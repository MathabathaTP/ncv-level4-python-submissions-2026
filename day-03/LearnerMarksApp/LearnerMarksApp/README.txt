NCV LEVEL 4 - LEARNER MARKS MANAGEMENT SYSTEM

RUN IN THONNY
Open learner_marks_app.py in Thonny and press F5.

CREATE THE WINDOWS EXE
On Windows, install Python 3.10 or newer (with PATH/py launcher enabled).
Double-click build_windows_exe.bat with an internet connection.
The executable will be created at dist\LearnerMarksManager.exe.
You can then run the EXE without installing Python on the destination Windows PC.

NOTE: A Windows EXE must be built on Windows. This package includes the exact build script,
not a precompiled Windows executable.

FEATURES
- All five assignment starter learners
- Add learner with valid marks; find, rename, add mark, confirm delete
- Descending bubble-sort ranking
- Demonstrations for Q1-Q4, expected/actual automated tests for Q6
- Export text report and save learner data in your home folder
- Uses only Python standard library at runtime

SUBMISSION
Take screenshots of the demonstrations and tests from Thonny and add a 3-5 sentence
reflection to your own Word/PDF submission. Fill in your name and student number in the
source code header before submitting. The assignment specifically asks for a .py file and
Word/PDF evidence, so an EXE alone is not sufficient.
