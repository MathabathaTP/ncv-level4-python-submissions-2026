Industrial sorting task

When a box is detected, the controller checks its type. If the type is metal, activate the sorting arm. Otherwise, let the box continue. If an emergency stop is active, stop all movement.

    STOP motor

🔤 C++ Programming Fundamentals

Arduino program structure

const int sensorPin = 2;
const int ledPin = 13;
bool boxDetected = false;

void setup() {
  pinMode(sensorPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  boxDetected = digitalRead(sensorPin);
  digitalWrite(ledPin,
               boxDetected ? HIGH : LOW);
}

setup() runs once; loop() repeats. const declares a value that cannot be reassigned.

Part 4 of 8

🔀 Decisions with if / else

A robot makes decisions using Boolean conditions.

Safety-first control

if (emergencyStop) {
  motorOn = false;
  armOn = false;
} else if (boxDetected && metalDetected) {
  motorOn = true;
  armOn = true;
} else {
  motorOn = true;
  armOn = false;
}

&& means AND; both conditions must be true. The emergency stop takes priority in this simplified logic model.

🔁 Loops and Functions

Repetition

for (int count = 1; count <= 5; count++) {

A for loop repeats a known number of times. Arduino's loop() function is repeatedly called by the runtime.

Controller code

void controlRobot(bool stop,
                  bool box,
                  bool metal) {
  if (stop) {
    motorOn = false;
    armOn = false;
    return;
  }
  motorOn = true;
  armOn = box && metal;
}
Real machinery requires validated safety hardware, interlocks and risk assessment. A browser simulation is not a safety-rated controller.
